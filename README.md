# StudentSpend

> A full-stack student finance management dashboard built with Flask and SQLite.

StudentSpend is a web-based personal finance management application designed to help students track daily expenses, manage monthly budgets, analyze spending patterns, and export transaction data.

The project focuses on providing a clean, responsive dashboard with authentication, expense management, analytics, and budget tracking.

---

## Features

- User registration and login
- Secure password hashing
- Add, edit, and delete expenses
- Monthly expense tracking
- Monthly budget management
- Budget usage and remaining balance
- Category-wise spending analysis
- Recent transaction history
- Spending visualization
- CSV expense export
- Search and filtering
- Responsive finance dashboard
- SpendAI assistant interface
- SQLite database integration
